เริ่มต้นใช้งาน

ระบบทำงานบนเบราว์เซอร์ (Chrome, Safari, Edge) ทั้งบนคอมพิวเตอร์ แท็บเล็ต และมือถือ ไม่ต้องติดตั้งโปรแกรม

  1. กด สมัครใช้งาน กรอกชื่อร้าน ผู้ติดต่อ อีเมล และรหัสผ่าน ระบบเปิดบัญชีทดลอง 14 วันให้ทันที
  2. เข้าสู่ระบบ แล้วไปที่ ตั้งค่า เพื่อใส่ชื่อร้าน ที่อยู่ และเลขผู้เสียภาษี (จะไปแสดงบนเอกสาร)
  3. เพิ่ม สถานที่เก็บ (คลังหลัก, หน้าร้าน, ชั้น A1 ฯลฯ)
  4. เพิ่มสินค้าและตั้งยอดสต็อกเริ่มต้น

สินค้าและหน่วยนับ

เพิ่มสินค้า

เมนู สินค้า → + เพิ่มสินค้า กรอกรหัสสินค้า ชื่อ บาร์โค้ด หมวดหมู่ เบอร์อะไหล่ รุ่นรถที่ใช้ได้ ต้นทุน ราคาขาย และจุดสั่งซื้อ

หลายหน่วยนับ

ตั้ง หน่วยหลัก (หน่วยที่นับสต็อก เช่น ชิ้น) และ หน่วยแพ็ก พร้อมอัตราแปลง เช่น 1 กล่อง = 12 ชิ้น เวลาซื้อหรือขายเลือกได้ว่าจะคิดเป็นหน่วยไหน ระบบแปลงเป็นหน่วยหลักให้อัตโนมัติ

บาร์โค้ด

ช่องค้นหาในหน้าขายและรับสินค้ารองรับเครื่องอ่านบาร์โค้ด ยิงบาร์โค้ดแล้วรายการจะถูกเพิ่มทันที

สต็อกและสถานที่เก็บ

เมนู สต็อก แสดงจำนวนคงเหลือของสินค้าแต่ละรายการแยกตามสถานที่เก็บ

  • ปรับยอด — ใช้ตอนนับสต็อกหรือตั้งยอดยกมา ระบุคลัง จำนวนใหม่ และเหตุผล
  • โอนย้าย — ย้ายของระหว่างคลัง เช่น จากคลังหลักมาหน้าร้าน
  • ประวัติความเคลื่อนไหว — ทุกการรับเข้า ขายออก ปรับยอด และโอนย้าย ถูกบันทึกพร้อมวันเวลา เอกสารอ้างอิง และผู้ทำรายการ

สินค้าที่ต่ำกว่า จุดสั่งซื้อ จะขึ้นสีส้มในหน้าสต็อกและปรากฏในแดชบอร์ด

จัดซื้อและรับสินค้า

  1. เมนู จัดซื้อ → + ใบสั่งซื้อ เลือกซัพพลายเออร์ เพิ่มรายการสินค้า จำนวน หน่วย และราคาซื้อ
  2. บันทึก ใบสั่งซื้อจะอยู่ในสถานะ รอรับของ
  3. เมื่อของมาถึง กด รับสินค้า เลือกคลังที่จะเก็บ ระบบเพิ่มสต็อกและอัปเดตต้นทุนล่าสุดให้

ขายและออกเอกสาร

  1. เมนู ขาย → + เปิดบิล เลือกลูกค้า (หรือ "ลูกค้าทั่วไป") และคลังที่ตัดสต็อก
  2. ค้นหาสินค้าด้วยชื่อ รหัส หรือยิงบาร์โค้ด ปรับจำนวน หน่วย และราคาได้ต่อรายการ
  3. เลือกการชำระ เงินสด / โอน (ชำระทันที) หรือ เครดิต (ตั้งเป็นลูกหนี้)
  4. บันทึกแล้วกด พิมพ์ เพื่อออกใบเสร็จ / ใบส่งของ / ใบกำกับภาษี

ลูกหนี้ วางบิล รับชำระ

บิลที่ขายแบบเครดิตจะรวมอยู่ในเมนู ลูกหนี้ แยกตามลูกค้า

  • ใบวางบิล — เลือกบิลค้างชำระหลายใบของลูกค้ารายเดียวกัน ออกเป็นใบวางบิลหนึ่งฉบับเพื่อส่งให้ลูกค้า
  • รับชำระ — บันทึกยอดที่รับ (เงินสด/โอน/เช็ค) ระบบตัดยอดค้างของบิลให้

รายงาน

  • มูลค่าสต็อก — จำนวน × ต้นทุน แยกตามคลังและหมวดหมู่
  • สินค้าใกล้หมด — รายการที่ต่ำกว่าจุดสั่งซื้อ
  • ยอดขาย — รายวัน / รายเดือน แยกเงินสดและเครดิต
  • กำไรขั้นต้น — ราคาขาย − ต้นทุน ต่อบิลและต่อสินค้า
  • สินค้าขายดี — จัดอันดับตามจำนวนและยอดเงิน
